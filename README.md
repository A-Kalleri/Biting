# Bitting

Bitting is an esoteric programming language based around bit-level operations.

Bitting currently has two versions:

## Bitter

**Bitting-bitter** is the bare-bones version of Bitting. It provides a low-level,
manual approach to programming with bits.

Bitter currently has:

- No loops
- Fixed operations
- Explicit bit manipulation

See the [grammar](docs/BITTER_GRAMMAR.md) for the language syntax.

The execution flow is described in [Execution](docs/BITTER_EXECUTION.md)

## Building

```sh
make bitter
```

## Usage

```sh
bitter <filename>.bitb
```

## Sweet

**Bitting-sweet** is planned to be a more flexible and easier-to-use version of bitting.

it will provide higher-level features such as:

- Loops
- ASCII variables
- Functions
- Bit array
