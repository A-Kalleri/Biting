# Bitter Execution

Bitter executes a program sequentially from the beginning of the source to the end.

Each operation is evaluated in order, and its result is stored in the LHS register.

## Modules

### Reader

The reader module is responsible for buffering the source file. it loades the source file into memory in segments.

>[!NOTE]
>A segment currently is `256` bytes.

### Lex

The lex module is responsible for performing lexical analysis on the source file.
it requests the **Reader** to fill the buffer whenever the current buffer has been tokenized and more source data is required.

### Parser-eval

The parser-eval module is resposible for parsing and evaluating the tokens generated by the **Lex** module.

### Execution pipline

```text
                  ┌─────────┐
                  ↓         │
start → reader → lex → parse-eval → end
          ↑       │ 
          └───────┘
```

## Registers

Bitter currently has 4 internal registers:

### LHS

The **LHS** (Left-Hand-Side) register stores the result of the current operation.

Operators accumulate their results into LHS.

LHS can contain:

- `0`
- `1`
- Empty

When writing a line `1 | 0` the program loads `1` to LHS automatically.

When `1` a single operand, the value is loaded into LHS.

A value cannot be loaded into LHS while it already contains a value.

The `.` operator is used to reset LHS.

### RP

The **RP** (Print) register stores a value that can be printed using the `<` operator.

RP can contain:

- `0`
- `1`
- Empty

### RHS

The **RHS** (Right-Hand-Side) register stores the other value of the binary operation.

After every operation it is emptied.

RHS can contain:

- `0`
- `1`
- Empty

### OP

The **OP** (Operation) register stores the opcode of the operation.

It is also emptied after an operation.

It can store any opcode of the boolean operation supported by the language.

### RR

The **RR** (Read) register stores the value that is read from the standard input using `?` operator.

It holds the user input `1` or `0`.

## Variables

Bitter provides 256 variables:

```text
x0 - x255
```

Each variable can contain:

- `0`
- `1`
- Empty

All variables are initialized to empty when execution begins.

## Execution Flow

An operation is evaluated and its result is stored in LHS.

For example:

```text
1 | 0
```

First the value `1` is loaded into LHS, then the value `|` is loaded into OP and finally the value `0` is loaded into RHS preparing for the operation.
The result is then written back to LHS and the other registers, RHS and OP are emptied.

Finally, LHS has the value `1`.

## Grammar

### Program

```text
program     ->  statement
```

### statements

```text
statement   ->  expression,
                expression feed identifier,
                expression feed register,
                register feed identifier,
                register feed register,
                show,
                read,
                reset,
                not

register    ->  RP

reset       ->  .

feed        ->  >

show        ->  <

read        ->  ?

not         ->  ~,
                !
```

### Expression

```text
expression  ->  operand,
                operand operator operand,
                operand (operator operand...)
```

### Operators

```text
operator    ->  |
                &
                ^
```

### Operands

```text
operand     ->  0,
                1,
                identifier
```

### Identifiers

```text
identifier  ->  xdigit

digit       ->  1, 2, 3, 4, 5, 6, 7, 8, 9, 0
                - combinations till '255'
```
